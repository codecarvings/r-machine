## How to sign

You do not need to send anything by email. On your first pull request a bot will
post a comment asking you to accept this agreement. Reply on that pull request
with exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

Your acceptance is recorded, with your GitHub username and the commit it applied
to, in the `cla-signatures` branch of this repository. That record is the
evidence of the licence you granted, and is kept for as long as the Project
distributes Your Contribution. You will not be asked again for subsequent pull
requests, unless this agreement changes.

If your employer requires a separate signed agreement, write to
<hello@codecarvings.com> before opening a pull request.
